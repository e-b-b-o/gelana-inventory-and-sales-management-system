# Project Documentation

These files are the persistent context for humans and AI agents.

Read in this order:

1.  `../AGENTS.md`
2.  `instruction.md`
3.  `project_plan.md`
4.  `project_progress.md`
5.  `project_decisions.md`
6.  `src.md`
7.  `database.md` / `api.md` as relevant
8.  `deployment.md` when preparing deployment
9.  `contributing.md` for development conventions

The documentation must evolve with the codebase. `project_plan.md`
defines what to build, `project_progress.md` defines what has been built
and what comes next, and `project_decisions.md` preserves why important
choices were made.
