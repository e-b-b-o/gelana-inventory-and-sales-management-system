# gelana-inventory-and-sales-management-system

A multi-branch inventory and sales management system built with React, TypeScript, Express and PostgreSQL.

## Development Commands

- `npm run dev:web` - Start the frontend development server
- `npm run dev:api` - Start the backend development server
- `npm run typecheck` - Run TypeScript compiler checks across all workspaces
- `npm run build` - Build all workspaces
- `npm run lint` - Run linter across all workspaces
